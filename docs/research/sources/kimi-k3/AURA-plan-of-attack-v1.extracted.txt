 SECTION 02
 The target spec — Suno 2026, grounded in 150 frames. 
 Every feature below is tied to sampled frames from Simon Crowe's Suno tutorial, followed by what our clone needs to match it.
 #013–018 Simple mode
 1 prompt + dice randomizer → 4 variants (2× v4.5, 2× v5.5). Ours: prompt → LLM lyric + style expansion → n-ranked 2 best variants.
 #017 · #046 Advanced mode
 Song Description, Lyrics (Write / Prompt / Instrumental), Exclude Styles, Vocal Gender, Weirdness %, Style Influence %, Duration, model picker, tag suggestions. Ours: form state → generation params — ACE-Step supports CFG / duration / tags natively; weirdness ≈ temperature / guidance mapping.
 #060–072 Create a Voice (Beta)
 Record / upload / library, ≥10s, consent phrase read-aloud. Ours: Seed-VC zero-shot (1–30s) or RVC train (5–15min) + pyannote consent verification — we keep Suno's ethics gate, for your own voice only.
 #076 Cover
 Swap voice / style, keep the song. Ours: Demucs vocal split → RVC / Seed-VC convert → RMS-matched remix (reference pipeline: efegen/rvc-pipeline, 6GB VRAM).
 #089 Song Editor
 Section-labeled timeline (Verse / Pre / Chorus / Bridge) + lyrics pane. Ours: all-in-one (MIT) functional segmentation + WhisperX word alignment (±50ms).
 #092–136 Studio DAW
 Multitrack, version lanes, clip tempo / transpose / speed / volume, 133 BPM grid, undo, "Copy to Main Track". Ours: wavesurfer-multitrack + Web Audio; non-destructive version stack in SQLite.
 #113–125 Stems
 Extract 8 stems, Insert All, per-stem prompted regen. Ours: BS-RoFormer / htdemucs_6s gives clean 6-way — 8-way is an industry gap (opportunity: transcription-to-MIDI as the "pro" substitute); per-stem regen via ACE-Step repaint.
 #132–137 Hum-to-instrument
 Mic → instrument → render. Ours: Basic Pitch (Apache-2.0, polyphonic pitch-bend) → MIDI → sampler / synth, or MusicGen-melody conditioning.
 #141–145 Export
 MP3 / WAV + share links. Trivial. We add stems ZIP + MIDI + project file — permanently, no caps. 
 #028 Pricing frame
 Free / Pro $10 / Premier $30, with download caps since 9/3/26. For us: n/a — kill credits entirely. That's the wedge. 
 SECTION 03
 Inside Suno — engineering anatomy. 
 Founded 2022 by four ex-Kensho ML engineers. Bark TTS (MIT, 2023) proves EnCodec-token autoregressive-transformer DNA. The community-consensus architecture — LLM lyric planner → AR codec-token model → diffusion decoder/renderer — is speculative and flagged as such: Suno publishes nothing.

 The fidelity leap. 44.1kHz-class output, breaths/vibrato, stereo imaging, ELO 1293. Critique: "stable but safe."

 Licensed WMG/BMG/Believe training, surgical edits, mashups, image/video prompts. Arena #1 (1142 Elo) but heavy backlash — "muffled," below v5 on WildSongBench. Older models retired.
 ORIGIN The DAW came by acquisition
 Suno's Studio DAW traces to the WavTool acquisition (Jun 2025) — bought, not built. A local clone can match it with wavesurfer-multitrack.
 DATA Leaked training diet
 Via the Nov 2025 breach (reported by 404 Media, Jul 2026): 2.01M YouTube Music clips / 113,879h , 152k h tagged YT, Pond5 62k h, IMSLP, Genius lyrics, Deezer, Jamendo, Freesound, podcast plans.
 EXPOSURE The legal arc
 RIAA suit Jun 2024 → Warner settled Nov 2025 (licensing + Songkick acquisition) → UMG/Sony still litigating; GEMA Munich ruling Jul 2026: memorization = reproduction. Meanwhile: $5.4B valuation, ~$300M ARR, 7M tracks/day.
 The lesson: Suno's moat is scraped-data scale + preference data + infrastructure. Its liability is that same data. We take the inverse position: CC0 + synthetic + your own voice. 
 SECTION 04
 The 80% gap, deconstructed. 
 Every modern song model — Suno included, by all verified signals — is the same four-stage pipeline. The magic is in the ingredients, not the shape.
 STAGE 1 LLM planner
 Prompt → structured lyrics with [Verse]/[Chorus] metatags + a style caption.
 → 
 STAGE 2 Acoustic generator
 DiT / flow-matching or codec-LM over 5–25Hz neural audio tokens. 2026 SOTA moved from RVQ to FSQ/CVQ low-frame-rate codecs.
 → 
 STAGE 3 Codec / VAE decoder
 Token sequence → raw waveform.
 → 
 STAGE 4 Post-chain
 Source separation → per-stem cleanup → master to −14 LUFS / −1dBTP → optional audio-SR upscale to 48kHz.
 Where Suno's extra quality actually comes from — evidence-weighted 
 01 Training-data scale / curation — 113k+ hours of (scraped) audio.
 02 Proprietary preference tuning — "My Taste" is RLHF-as-product.
 03 In-house stems conditioned into training — ACE-Step 1.5 copied this openly: trained on 6M stem-separated tracks.
 04 Best-of-n behind the scenes — Suno returns 2–4 survivors from a larger batch.
 05 Post-mix polish — separation, cleanup, mastering.
 Every lever except ①'s copyrighted scale has an open equivalent. The gap is measurable — and closable in stages (see Section 07).

 Cross-platform complaint themes = our attack surface 
 01 Export hostage-taking
 Caps, watermarks, walled gardens. "Export rights are the product." The #1 gap industry-wide.
 02 Credit-burn economics
 Pay for failed generations, no rollover, opaque credit math.
 03 Lyric / prompt adherence failures
 Ignored lyrics, mispronunciation, wrong voice gender — controllability is the #1 quality gap.
 04 Editing destroys the song
 Regenerate-and-pray; true section-sticky editing is unsolved everywhere.
 05 Dirty stems
 Secondary AI passes leave reverb artifacts, bleed, missing stems.
 06 No MIDI / DAW / VST export
 Only AIVA, Mureka Premier, and BandLab offer it. Pros demand it universally.
 07 Ownership ambiguity
 Rights attach at creation, no retroactive licensing, "(if any)" certificates.
 08 Trust & billing horror stories
 Unauthorized charges, cancellation friction, songs held hostage. Near-zero cost to beat.
 The winning formula — nobody ships all six
 Suno-class vocals + unlimited exports + clean stems + MIDI/DAW export + honest pricing ($0 local) + licensed/CC0 data
 AURA ships all six by construction: local, open, yours.

 SECTION 08
 Reference architecture & cost. 
 Local-first. Browser-on-localhost for v1, Tauri shell later. The engine sits behind an abstraction so backends swap freely.
 aura — system layout 
 ┌─ Desktop (Linux/Win/Mac): Tauri 2 shell (42MB vs Electron 168MB) or pure browser-on-localhost (v1)
│ React UI: Create panel (Simple/Advanced) · Library · wavesurfer-multitrack Studio · Stems drawer · Voice lab
├─ FastAPI worker + SQLModel/SQLite + asyncio.Queue + SSE progress (HeartMuLa Studio pattern — proven)
│ Lyrics: local LLM (Ollama) emitting Suno metatag grammar
│ Engine abstraction → backends: [local MLX/MPS on Mac] [local CUDA] [ serverless GPU burst ]
│ Generation: ACE-Step 1.5 turbo 8-step (draft) / SFT 50-step (render) / YuE2 (quality batch)
│ Ranker: n=8–16 → audiobox-aesthetics + SongEval + CLAP + lyric-WER → top 2 to UI 
│ Stems: Demucs (demucs-mlx 73× RT on Mac) / BS-RoFormer · Mastering: Matchering + pyloudnorm
└─ Storage: local-first library, WAV/MP3/stems-ZIP/MIDI export, no credits, no caps, ever 
 TIER ① Mac-only
 M3 Pro 36GB: draft at ~25s/song natively (MLX), render via cloud burst.
 < $15/mo @ 500 songs
 TIER ② Any NVIDIA 24GB box
 3090 / 4090: fully local, 2–10s drafts. No cloud dependency at all.
 $0 marginal / song
 TIER ③ Cloud-only
 RunPod serverless 4090 at $1.10/h active-seconds, scale-to-zero. A 2-variant song ≈ 1–1.5 GPU-min.
 $0.01–0.03 / song
 Renting beats owning until ~1,000+ songs/month. Scale-to-zero serverless means idle cost is exactly zero.
 Biggest infra risk: CUDA-stack fragility × 3 OSes (torch cu126/cu128, Blackwell sm_120, flash-attn pins, MPS bugs). Mitigate with per-OS pinned envs, Docker, and CI on all three. Avoid gcui-art/suno-api (dead since Dec 2025, ToS risk) and MusicGen (CC-BY-NC).
